# 英语图片/文档精读助手

把英文材料丢进来——**图片（截图、照片）或文档（PDF / Word / PPT / Excel / TXT / Markdown）**，自动完成识别、翻译、按等级标注生词。

**在线版（手机电脑都能用）**：https://wanyuchen999-ai.github.io/english-reader/

## 两种工作模式

| | 免 Key 内置模式（默认） | AI 模式（可选增强） |
|---|---|---|
| 需要注册/Key | **不需要** | 需要（智谱有免费模型） |
| 图片识别 | 本地 Tesseract OCR（浏览器内运行） | AI 视觉模型（更准） |
| 翻译 | 免费公共接口（谷歌，连不上自动切 MyMemory） | AI 翻译（更自然） |
| 生词标注 | 本地 8 级词库，一样全 | 一样 |
| 语法讲解 | 无 | 有 |

免 Key 模式的核心功能（翻译 + 生词标注 + 生词本）完全内置，**不消耗任何人的额度**；AI 模式只影响识别和翻译质量，并提供语法讲解。

## 功能一览

- 图片（jpg/png/截图）与文档（PDF / Word .docx / PPT .pptx / Excel .xlsx / TXT / Markdown / 字幕）都能分析
- 扫描版 PDF 自动转图片走识别；长文档自动分段排队
- 按身份（初中 / 高中 / 四级 / 六级 / 考研 / 雅思 / 托福 / GRE）标注生词，内置 18,800+ 词真实词库（含音标释义，离线判定）
- 点击 / 长按 / 右键任意单词：查释义、发音、标为生词
- 生词本（可复制 / 导出 Anki）、历史记录、全部保存在本设备，重开自动恢复

## 快速开始

1. 打开 [在线版](https://wanyuchen999-ai.github.io/english-reader/)（国内网络可直接访问）
2. 拖入图片或文档 → 自动分析
3. （可选）点右上角「设置」切换 AI 模式，按提示注册智谱拿到免费 Key 填入

## 常见问题

**别人没 VPN 能用吗？** 能。网站托管在 GitHub Pages（国内直连可打开）；免 Key 模式的翻译连不上谷歌时会自动切换到 MyMemory 备用接口（质量稍逊）。OCR 和词库全部在本地运行，与网络无关。

**免 Key 模式识别/翻译不理想？** OCR 对清晰印刷体效果最好；翻译在开 VPN 时自动用谷歌（质量更好）。追求最佳效果请切 AI 模式。

**数据在哪？** 浏览器 localStorage（本设备）。清缓存会清掉，生词本可导出备份。

**旧版 .doc / .ppt / .xls？** 另存为 .docx / .pptx / .xlsx 或 PDF。
