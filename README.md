# 英语图片/文档精读助手

把英文材料丢进来——**图片（截图、照片）或文档（PDF / Word / PPT / Excel / TXT / Markdown）**，自动完成：

- **识别或提取英文原文**（图片走 AI 视觉识别；文档本地提取文字，扫描版 PDF 自动转图片再识别）
- **全文中文翻译**（逐段对照）
- **按你的身份标注生词**——内置初中 / 高中 / 四级 / 六级 / 考研 / 雅思 / 托福 / GRE 共 8 级真实词库（18,800+ 词，含音标和释义，本地离线判定）
- **语法结构讲解**——原文中划虚线的部分，点开看通俗讲解
- **重点短语**标注
- **点击 / 长按 / 右键任意单词**：查释义、听发音、标为生词
- **记忆功能**——你标注的生词、全部历史分析记录都保存在本设备浏览器里，关掉再开还在，还会自动恢复最近一次分析；换身份后所有文章的标注会即时重新计算

不装任何软件、不用注册小程序，**双击 `index.html` 就能用**（需要电脑上有 Chrome/Edge 等现代浏览器）。

---

## 一、快速开始（3 步）

1. **双击 `index.html`** 打开页面
2. 点右上角 **「AI 设置」**：
   - 服务商选 **「智谱 BigModel（推荐 · 有免费视觉模型）」**
   - 点提示里的链接去 [智谱开放平台](https://open.bigmodel.cn/usercenter/apikeys) 注册 → 创建一个 API Key（免费）
   - 把 Key 粘贴进来 → **测试连接** → **保存**
3. 拖一张图片或一个文档进页面（或 `Ctrl+V` 粘贴截图）→ 自动分析

> 模型默认 `glm-4v-flash`，是免费的。也可以换硅基流动、阿里百炼、Kimi 等任何 OpenAI 兼容接口。

## 二、支持的文件格式

| 格式 | 处理方式 |
|---|---|
| jpg / png / webp / 截图 | AI 视觉识别（自动压缩后上传） |
| PDF（文字版） | 本地 pdf.js 提取文字，AI 只做翻译讲解（更准、更省） |
| PDF（扫描版/图片版） | 自动检测：没有文字层时逐页转成图片走视觉识别（最多前 10 页） |
| Word .docx / PPT .pptx / Excel .xlsx | 浏览器内直接解包提取文字（旧版 .doc/.ppt/.xls 请先另存为新格式或 PDF） |
| TXT / Markdown / CSV / SRT 字幕等 | 直接读取 |
| 长文档 | 自动按段落分成多段排队分析，卡片标题标明「第 x/y 段」 |

## 三、页面功能

| 区域 | 说明 |
|---|---|
| 身份选择（我是：初中/高中/四级/…） | 决定什么算“生词”：只标高于你身份等级的词。切换后所有已分析文章的标注立即更新 |
| 「同时高亮我当前等级的词」 | 打开后，正在备考的这一级词也会淡蓝色标出（默认关） |
| 原文精读 | 橙色=超纲生词、红色=我标注的词、紫色虚线=语法结构、绿色点线=重点短语、灰色点线=专有名词。每段下面是中文翻译 |
| 生词 | 自动列出本文生词：等级、音标、释义，可发音、可标注 |
| 语法 | 逐条讲解本文出现的语法结构 |
| 我的生词本 | 全部标注的词，按时间倒序。可复制、可导出 Anki 导入用的 txt |
| 历史记录 | 最近 30 次分析，点击重新打开 |

**单词交互**：单击任何单词弹出卡片（等级 / 音标 / 释义 / 发音 / 标注）。手机上长按、电脑上右键也一样。

## 四、常见问题

**打不开或提示“连不上 AI”？**
用文件夹里的 `启动.bat` 重新打开（走本地服务，可绕过浏览器对本地文件的联网限制）。

**数据存在哪？会丢吗？**
全部在浏览器 localStorage（本设备）。清浏览器缓存/网站数据会清掉它；生词本可用「导出 Anki 文件」备份。

**PDF 提取出来乱码或缺字？**
该 PDF 可能是扫描版（整页是图片），程序会自动转成图片走视觉识别；也可以直接截图后按图片上传。

**旧版 .doc / .ppt / .xls 打不开？**
用 Office/WPS 另存为 .docx / .pptx / .xlsx 或 PDF 即可。

**识别不准 / 翻译不满意？**
点结果卡片右上角「重新分析」再来一次；图片越清晰、文字越大效果越好。

**能在手机上用吗？**
目前是电脑网页版。想手机用可以把 `english-reader` 文件夹发给任何能开网页的设备，或以后帮你部署成在线网址。
